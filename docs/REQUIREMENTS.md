# Requisitos y alcance

## Para ejecutar la demo

Windows x64 y la carpeta completa del paquete. El runtime .NET está incluido; no se requiere Godot, login o conexión durante la práctica. El equipo comprobado fue un i7-7700HQ con Quadro M1200 y renderer Compatibility/OpenGL a 1280×720.

Ese equipo es una referencia de prueba, **no un requisito mínimo garantizado**. Aún falta medir en otras computadoras y realizar una prueba limpia sin herramientas de desarrollo.

## Para desarrollar

Godot .NET 4.7.2 y SDK .NET 10.0.401; plantillas coincidentes para exportar. [Instrucciones](DEVELOPMENT.md).

## Para probar OpenXR

Visor/controladores compatibles con un runtime OpenXR Windows activo, conectado a PC; capacidad gráfica y frecuencia por verificar. No se ha seleccionado un visor ni validado un perfil físico. No hay garantía universal; no se afirma compatibilidad Android autónoma.

## Alcance educativo

Movimiento articular/cartesiano, referencias, enseñanza de puntos, lenguaje acotado, ciclo de celda, señales, fallas y recuperación. Seguridad virtual y colisiones aproximadas. Sin control de robot físico, PLC, nube, multijugador o funciones de certificación.
