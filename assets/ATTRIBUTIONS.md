# Recursos y créditos

El robot, suelo, celda, pinza, pieza, estaciones, sensor, obstáculo, soporte, puerta, controles y paneles se generan mediante geometría y código del proyecto. No se incluyen modelos, texturas ni sonidos externos.

Las imágenes de `docs/media/*.png` son capturas del ejecutable o de la escena del proyecto. `docs/media/banner.svg` es una ilustración vectorial creada para esta documentación; representa la identidad visual, no un modelo cinemático del robot.

La interfaz utiliza la fuente predeterminada de Godot. El mapa `godot/robot_action_map.tres` se genera con el SDK oficial. Godot y .NET conservan sus avisos completos en [notices](notices); se incluyen al distribuir la demo Windows.

La licencia del código y recursos propios sigue pendiente de decisión del propietario. No se incorpora automáticamente la licencia de una dependencia al proyecto.

Todo recurso externo futuro debe registrar archivo, autor, URL de origen, licencia, modificaciones y avisos necesarios. No se usan interfaces o logos de fabricantes.
